# Module 1 — Les réseaux et protocoles (Semaines 1-2)

Formation SOC / Blue Team | GeniusClassrooms

## Objectif

Comprendre comment les données circulent sur un réseau — base indispensable pour analyser des attaques.

## Chapitres

1. [Chapitre 1 — Le modèle OSI](chapitre-01-modele-osi/README.md)
2. [Chapitre 2 — TCP et UDP](chapitre-02-tcp-udp/README.md)
3. [Chapitre 3 — Les protocoles essentiels (DNS, ARP, DHCP, HTTP/HTTPS)](chapitre-03-protocoles-essentiels/README.md)
4. [Chapitre 4 — Adressage IP et sous-réseaux](chapitre-04-adressage-ip-sous-reseaux/README.md)
5. [Chapitre 5 — Firewall, IDS, IPS et DMZ](chapitre-05-firewall-ids-ips-dmz/README.md)

## Fil rouge du module

Production progressive d'un **rapport d'analyse réseau**, comme un analyste SOC junior lors de sa première semaine — chaque exercice apporte une brique.

- **Fichiers PCAP fournis** — exercices d'analyse hors ligne
