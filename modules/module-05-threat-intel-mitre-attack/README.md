# Module 5 — Threat Intelligence & MITRE ATT&CK (Semaine 6)

Formation SOC / Blue Team | GeniusClassrooms

## Objectif

Connaître les frameworks de référence et savoir contextualiser une attaque.

## Sous-chapitres théoriques

- 5.1 — MITRE ATT&CK : tactiques → techniques → sous-techniques, les 14 tactiques principales, exemples (T1078, T1059).
- 5.2 — Cyber Kill Chain : les 7 étapes (Reconnaissance → ... → Actions), blocage à chaque étape.
- 5.3 — Pyramid of Pain : hash → IP → domaine → artefact réseau → outils → TTP, pourquoi bloquer les TTP est plus efficace.
- 5.4 — IOCs et leur utilisation : types d'IOC, VirusTotal, MalwareBazaar, enrichissement de contexte.

## Exercices pratiques (100% local / léger en ligne)

- Lire et résumer 3 fiches MITRE ATT&CK (attack.mitre.org)
- Mapper une attaque décrite en 5 étapes sur la Kill Chain
- Analyser 2 hashes suspects sur VirusTotal
- Classer 10 IOCs dans la Pyramid of Pain

## Projet du module — Analyse d'un rapport d'attaque réel

À partir d'un rapport d'incident public (ex. rapport APT CISA) : mapper les techniques sur MITRE ATT&CK, placer l'attaque sur la Kill Chain, identifier les IOCs. Livrable : fiche de 2 pages.
